# Day 6 – Counter App

## Project Description

Today I built a simple Counter App using HTML, CSS, and JavaScript.

The Counter App allows the user to increase, decrease, and reset a number by clicking buttons.

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

Today I learned:

- How JavaScript works with HTML
- How to connect an external JavaScript file to HTML
- How to use variables with `let`
- How to select HTML elements using `document.getElementById()`
- How to listen for button clicks using `addEventListener()`
- How to increase and decrease a number
- How to change HTML content using `textContent`
- How to use functions
- How to use `if` statements
- Basic DOM manipulation

## How the Counter Works

The counter starts at 0.

- The `+` button increases the counter.
- The `-` button decreases the counter.
- The `Reset` button returns the counter to 0.
